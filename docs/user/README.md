# User manual

This directory holds **user-facing guides** for Loom — how to install,
configure, and use the CLI.

## What goes here

- Getting started (installation, first run)
- Configuration reference (`settings.json`, environment variables, cascades)
- Slash command reference (per-command usage and examples)
- Permission modes and tool permissions
- Headless / server mode cookbook
- Keyboard shortcuts and terminal configuration

## Current state

The repo-root [`README.md`](../../README.md) currently serves as the de facto
user manual (features, build, run, flags, config, slash-command tables).
Guides will be extracted here incrementally.

## Naming convention

`kebab-case.md` — e.g. `getting-started.md`, `settings-reference.md`.
