## Implemented behavior and limits

Class-only direct `style ID` now owns a bounded semantic style channel from
source parsing through Canvas, cropped rows, cache and final FTXUI Elements.
The initial property set is fill, stroke, color and stroke-width; colors are
hex3/4/6/8 and white, with alpha zero admitted only for fill. Width0..64 maps
to normal or bold border at4. Palette hue roles project colors; filled labels
use palette.text and source foreground on fill is explicitly disclosed as
unprojected. Browser colors and implicit empty-compartment defaults remain
foreign debt. Existing Class terminal geometry is preserved.

The plain legend retains exact physical declarations, escaped TAB disclosure,
normalized duplicate counts and adaptation details. Seven entries plus the key,
240 cells per row, the original canvas/source limits and one-million producer
Work remain bounded. Unsupported colors, properties, references, targets or
space requirements preserve the complete source. Undefined CSS classes,
class assignments, links and callbacks are not admitted by D1a.

The lazy parallel channel leaves old style-free glyph and measured Work pins
unchanged. Cache entries own semantic rows and measured layout debit; they
resolve the current theme on every render and charge the caller before cloning.
Styled byte accounting includes capacities and metadata with overflow checks,
oversized entries bypass eviction, and insertion rolls back strongly. ASCII
keeps source for applied styles. Literal member box characters never substitute
for the actual Canvas line bits when painting compartments.
