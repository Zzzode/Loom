## 2. The decision: medium-inert leaves are drawn and disclosed

`look: handDrawn` is rough.js stroke styling. A terminal draws table glyphs, so
the skin has no terminal expression: accepting the leaf changes **no glyph** —
every art row above the disclosure footer is byte-identical to the twin
rendered from the same source without the frontmatter block (the durable gate
asserts this row by row). The disclosure costs one or two footer rows, so a
source that only just fit its Work or height budget can still fall back; the
claim is scoped to layouts that fit. The rows therefore render their structure
and disclose the unapplied skin:

```
config.look=handDrawn -> source node style; not applied
config.handDrawnSeed=1 -> sketch jitter seed; not applied
```

This follows the D-440 palette precedent and the D-442 agentflow
`look: handDrawn` admission. `look: neo` (a different upstream skin with its
own negative in D-442) and every other value stay whole-source.

## 3. Mechanism

- `flow_envelope_body` (`src/ui/visual/mermaid_impl.cpp`) evaluates every closed
  profile on `config_fields = fields & ~(Look | Seed)`, so the sketch leaves may
  accompany any already-admitted profile or stand alone (`bare_look`).
- `look` accepts `handDrawn` bare or single/double-quoted; `handDrawnSeed` is a
  positive decimal of at most nine digits, no leading zero.
- The FS-8 test-only preview seam (`set_flow_handdrawn_preview_for_testing`,
  `flow_handdrawn_preview_active`, the cache namespace bypass) is **deleted**:
  with the leaf admitted in production the seam had no remaining consumer.

Twelve of the twenty-two rows also appear in the FS-3a/FS-4h/FS-6/FS-7b
cohort ledgers, which had recorded their whole originals as source behind the
look gate. Those four ledgers and generators are re-baselined in this slice
(whole states drawn / narrow source, FS-6 whole draws 24 -> 32 with body-only
scope 14 -> 6, FS-4h 5 -> 7, FS-7b 2 -> 3, FS-3 authoritative row now
whole-drawn), each with a `d814` review addendum; the D-814 matrix branch sits
before those branches, so the whole-source disposition is owned here while the
FS gates keep the body-track coverage.

The 22 rows carry the disclosure footer, which is unclaimed ink for the
  Flow400 geometry oracle, so they admit through the reviewed source-byte
  cohort path (never through the oracle), exactly like the D-470 projection
  rows:
  `tools/mermaid/flow-look-cohort.json` (generated by
